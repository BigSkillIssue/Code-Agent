# Configuration reference

Generated by `forge config schema --markdown` from `ForgeConfig` in `src/forge/config.py`.

Forge reads, later files winning: built-in defaults, `~/.forge/forge.toml`, the project's
`.forge/config.toml`, the selected profile (`-p NAME` or `profile = "NAME"`), `FORGE_*`
environment variables (`FORGE_SANDBOX__MODE=read-only`; `__` separates levels), then CLI
flags. A project file may set `[providers]`, `[mcp_servers]` and `[hooks]` only after
`forge trust`. `forge config check` prints the effective configuration (secrets masked).

## Top level

| key | type | default | description |
| --- | --- | --- | --- |
| `profile` | str | `"default"` | Profile to apply from `[profiles.*]` (`-p` overrides it). |
| `providers` | table of ProviderConfig | `{}` | Model endpoints by name; see `[providers.<name>]`. Common providers have presets. |
| `models` | table of ModelOverride | `{}` | Capability and price overrides per `"provider/model"`. |
| `roles` | table of list of str | - | Model fallback chain per role: `coder = ["anthropic/claude-sonnet", "openai/gpt-5"]`. |
| `sandbox` | SandboxConfig | - | See `[sandbox]`. |
| `approval` | ApprovalConfig | - | See `[approval]`. |
| `permissions` | PermissionsConfig | - | See `[permissions]`. |
| `limits` | LimitsConfig | - | See `[limits]`. |
| `web` | WebConfig | - | See `[web]`. |
| `mcp_servers` | table of McpServerConfig | `{}` | MCP servers to connect; see `[mcp_servers.<name>]`. |
| `hooks` | table of list of HookConfig | `{}` | Shell hooks per event: session_start, prompt_submit, pre_tool, post_tool, step_done, pre_compact, stop, subagent_stop. |
| `profiles` | table of table of Any | `{}` | Named overlays, e.g. `[profiles.ci] approval = { policy = "never" }`. |

## [roles]

Built-in defaults:

```toml
[roles]
refiner = ["openai/gpt-5-mini"]
planner = ["anthropic/claude-sonnet"]
coder = ["anthropic/claude-sonnet", "openai/gpt-5"]
reviewer = ["openai/gpt-5-mini"]
compressor = ["openai/gpt-5-mini"]
explore = ["openai/gpt-5-mini"]
```

## [sandbox]

Where commands may write and whether they may use the network.

| key | type | default | description |
| --- | --- | --- | --- |
| `mode` | `read-only` \| `workspace-write` \| `full-access` | `"workspace-write"` | `read-only`, `workspace-write` (project + temp folders) or `full-access` (no sandbox). |
| `network` | bool | `false` | Allow outgoing network from shell commands. |
| `writable_roots` | list of str | `[]` | Extra folders commands and file tools may write to. |

## [approval]

When Forge asks the user before acting.

| key | type | default | description |
| --- | --- | --- | --- |
| `policy` | `on-request` \| `always` \| `never` | `"on-request"` | `on-request` (ask when leaving the sandbox), `always` (ask before changes) or `never`. |

## [permissions]

Fine-grained `tool(specifier)` rules.

| key | type | default | description |
| --- | --- | --- | --- |
| `allow` | list of str | `[]` | Rules that run without asking, e.g. `bash(git status*)`. |
| `ask` | list of str | `[]` | Rules that always ask, e.g. `bash(git push *)`. |
| `deny` | list of str | `[]` | Rules that are refused, e.g. `bash(rm -rf *)`, `read_file(./.env*)`. |

## [limits]

Hard limits per step and per session.

| key | type | default | description |
| --- | --- | --- | --- |
| `max_turns_per_step` | int | `40` | Model turns an agent gets per plan step. |
| `max_step_attempts` | int | `3` | Check failures before a step counts as failed. |
| `max_clarify_rounds` | int | `3` | Rounds of clarifying questions. |
| `max_parallel_agents` | int | `4` | Sub-agents running at the same time. |
| `max_cost_usd` | float | `5.0` | Budget for the whole session; work stops cleanly when it is used. |
| `compact_at` | float | `0.7` | Share of the context window at which old turns are summarized. |
| `reset_at` | float | `0.9` | Share of the context window at which the context is rebuilt from the plan. |
| `mcp_defer_threshold` | int | `40` | Above this many MCP tools, schemas load on demand via `tool_search`. |
| `max_web_searches` | int | `200` | Web searches per session. |

## [web]

Web search backend selection.

| key | type | default | description |
| --- | --- | --- | --- |
| `search_backend` | `native` \| `brave` \| `tavily` \| `searxng` | `"native"` | `native` (the model's own search), `brave`, `tavily` or `searxng`. |
| `search_api_key_env` | str | `""` | Variable with the backend's API key (for `searxng`: its URL). |

## [providers.<name>]

One API endpoint Forge can talk to.
One table per provider name.

| key | type | default | description |
| --- | --- | --- | --- |
| `kind` | `openai_compat` \| `anthropic` \| `google` \| `litellm` | `"openai_compat"` | Adapter: `openai_compat`, `anthropic`, `google` or `litellm`. |
| `wire` | `chat` \| `responses` | `"chat"` | For `openai_compat`: Chat Completions (`chat`) or Responses (`responses`). |
| `base_url` | str (optional) | unset | API URL; `bedrock://<region>` and `vertex://<project>/<region>` select those clouds. |
| `api_key_env` | str (optional) | unset | Environment variable holding the API key (keys are never stored in config). |
| `headers` | table of str | `{}` | Extra HTTP headers. |

## [models."<provider>/<model>"]

Capability overrides for one `provider/model`; unset fields keep the catalog value.
Unset fields keep the built-in catalog value.

| key | type | default | description |
| --- | --- | --- | --- |
| `context_window` | int (optional) | unset | Tokens the model accepts. |
| `max_output` | int (optional) | unset | Tokens the model may write per answer. |
| `tools` | bool (optional) | unset | Native tool calling (false: prompt-based tools are used). |
| `parallel_tools` | bool (optional) | unset | Several tool calls per answer. |
| `vision` | bool (optional) | unset | Reads images. |
| `reasoning` | bool (optional) | unset | Thinks before answering (reasoning effort is sent). |
| `prompt_cache` | bool (optional) | unset | Caches the stable prompt prefix. |
| `web_search` | bool (optional) | unset | Has a native web search tool. |
| `cost_in` | float (optional) | unset | USD per 1M input tokens. |
| `cost_out` | float (optional) | unset | USD per 1M output tokens. |

## [mcp_servers.<name>]

An MCP server: a local command (stdio) or a URL (HTTP).
Set `command` (stdio) or `url` (HTTP).

| key | type | default | description |
| --- | --- | --- | --- |
| `command` | list of str (optional) | unset | Command line (list) of a stdio server, or the shell command of a hook. |
| `env_keys` | list of str | `[]` | Environment variables passed to the server. |
| `url` | str (optional) | unset | URL of an HTTP (streamable) server. |
| `headers_env` | table of str | `{}` | HTTP header -> environment variable holding its value. |

## [hooks] entries

A shell hook; `match` is a regex on tool names (empty = every tool).
Written as `post_tool = [{ match = "edit_file", command = "ruff format {path}" }]`.

| key | type | default | description |
| --- | --- | --- | --- |
| `match` | str | `""` | Regex on the tool name (tool events only; empty = every tool). |
| `command` | str | - | Command line (list) of a stdio server, or the shell command of a hook. |
